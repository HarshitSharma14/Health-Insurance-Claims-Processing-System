# Deliverables

This folder holds everything asked for in the assignment, in one place, so a reviewer
doesn't have to dig through the repo to find each piece.

1. `01-working-system.md` is how to reach the live app and how to run it locally.
2. `02-architecture.md` explains what I built and why.
3. `03-component-contracts.md` is the interface for every component, precise enough to
   rebuild any one of them without reading the code.
4. `04-eval-report.md` walks through all 12 test cases, what the system decided, and
   whether it matched.
5. `05-demo-video.md` is the outline I used for the recording, kept here so you can
   follow along with the video.

The full machine-generated eval output, including every raw trace, lives in
`../eval/eval_report.md`. The shorter version in this folder is the readable summary.
